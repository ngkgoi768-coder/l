# Trolling — мод для Minecraft 1.20.1 (Forge 47.3.0)

Добавляет вкладку творческого режима **ТРОЛЛИНГ** с предметом **КЕЙН**.

## Как работает
- ПКМ предметом **КЕЙН** — твой игрок превращается в модель из `caine.geo.json`.
  Повторное ПКМ — снова обычный игрок.
- Стоишь на месте — играет анимация `idle`, идёшь — `walk`.
- Пока ты КЕЙН, можно летать даже в выживании: дважды нажми прыжок (как в творческом).
  Урон от падения не наносится. Когда превращение выключено, полёт забирается обратно.
- Превращение сохраняется между входами в игру и видно другим игрокам.
- Способности (список справа на экране, пока ты КЕЙН; клавиши меняются в Настройки -> Управление -> ТРОЛЛИНГ):
  - **Невидимость** (по умолчанию X): ты полностью исчезаешь (тело, броня, предметы в руках, ник),
    на месте исчезновения 5 секунд висит облако white_smoke. Повторное нажатие делает тебя видимым.
    Когда превращение выключено, невидимость сбрасывается.
- Остальные анимации из файла (`spawn`, `told`, `hit`) сейчас не используются.

## Свои файлы
Заменить модель, анимации или текстуру можно прямо в `src/main/resources/assets/trollmod/`:
`geo/caine.geo.json`, `animations/caine.animation.json`, `textures/entity/caine.png`.
Размер модели меняется константой `SCALE` в `client/CaineModel.java` (сейчас 0.5, примерно рост игрока).

## Сборка
Нужен JDK 17:

    ./gradlew build        # jar в build/libs/trollmod-1.0.0.jar
    ./gradlew runClient    # запуск игры для проверки

На GitHub сборка идёт сама (вкладка Actions, артефакт `trollmod-jar`).
